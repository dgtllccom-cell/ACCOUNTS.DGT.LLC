# Store privacy declarations (same for DGT.llc B and DGT.llc BS)

## Google Play — Data safety form
* Data collected and linked to the user: **Name, e-mail/user ID** (account), **Photos** (only when the user attaches a document), **Other user content / files and docs** (business documents), **Device or other IDs** (push token, only if notifications are allowed).
* Purpose: App functionality, account management, security/fraud prevention. **Not** for advertising, analytics or personalisation.
* Shared with third parties: **No** (hosting/database providers act as processors for DGT).
* Encrypted in transit: **Yes** (HTTPS). Users can request deletion: **Yes** (through their organisation's administrator; no self sign-up).
* Location: not collected. Contacts, SMS, calendar: not collected.
* Target audience: 18+ business users. Ads: none. Government/financial app declarations: not a financial-services provider (a business accounting tool used by the company's own staff).

## Apple — App Privacy ("nutrition labels")
* Contact info (name, e-mail) — linked to user — App Functionality.
* User content (photos/files the user uploads, business records) — linked to user — App Functionality.
* Identifiers (push token) — linked to user — App Functionality.
* Tracking: **No** (no ATT prompt needed). No third-party SDKs that collect data.
* Camera usage description (already in Info.plist): "to attach document photos".

## Samsung Galaxy Store
Same declarations; choose Business category; no in-app purchases; age rating 3+/Everyone.
